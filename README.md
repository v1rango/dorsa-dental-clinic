# وب‌سایت کلینیک دندانپزشکی و زیبایی دُرسا (Dorsa Dental Clinic)

یک وب‌سایت پزشکی و کلینیکی فوق‌مدرن، لوکس و کاربرپسند با رنگ‌بندی تخصصی حوزه دندانپزشکی (فیروزه‌ای، آبی بالینی، سبز سلامت و سفید مرواریدی)، اسلایدر تعاملی قبل و بعد اصلاح طرح لبخند، محاسبه‌گر هوشمند هزینه و اقساط دندانپزشکی، و سیستم آنلاین رزرو نوبت.

> **توسعه‌دهنده و معمار وب‌سایت:** [آراد وفایی](https://aradvafaee.ir)  
> **پورتفولیو و استودیو دیجیتال:** [aradvafaee.ir](https://aradvafaee.ir)  
> **ارتباط مستقیم:** ۰۹۳۹۴۶۰۶۰۱۳

## قابلیت‌ها و امکانات فنی شاخص

1. **پالت رنگی استاندارد سلامت و زیبایی دندان (Medical & Dental Palette):**
   - ترکیب فیروزه‌ای آرامش‌بخش، آبی بالینی (Clinical Teal/Cyan)، سبز زمرودی و طلایی شامپاینی جهت زیبایی لبخند.
   - تم دوگانه: **حالت روز پزشکی (Clean Medical Light - پیش‌فرض)** و **حالت تیره لوکس (VIP Dark Mode)**.
2. **اسلایدر تعاملی قبل و بعد اصلاح طرح لبخند (Before & After Slider):**
   - قابلیت جابجایی دستی یا لمسی خط تفکیک برای مشاهده تحول لبخند با لمینت سرامیکی و کامپوزیت بدون رفرش صفحه.
3. **محاسبه‌گر هزینه درمان و اقساط دندانپزشکی (Dental Cost Calculator):**
   - انتخاب نوع درمان (لمینت Emax سوئیسی، ونیر کامپوزیت آلمانی، ایمپلنت دیجیتال، ارتودنسی نامرئی و بلیچینگ).
   - انتخاب تعداد واحد دندان و پلن‌های پرداخت (نقدی با ۱۰٪ تخفیف، اقساط ۶ ماهه بدون کارمزد، و اقساط ۱۲ ماهه).
   - محاسبه بلادرنگ پیش‌پرداخت، مبلغ قسط ماهانه و تخمین هزینه کل درمان.
4. **سیستم آنلاین رزرو نوبت و مشاوره دندانپزشکی:**
   - انتخاب خدمت، پزشک معالج، شیفت و ارسال مستقیم مشخصات به واتساپ پذیرش کلینیک.
5. **معرفی تیم پزشکان و تجهیزات های‌تک:**
   - نمایش پزشکان با سوابق و شماره نظام پزشکی.
   - معرفی اسکنر سه‌بعدی iTero، لیزر بدون خونریزی و اتوکلاو کلاس B.
6. **کارت اختصاصی و رسمی طراح در فوتر (Developer Card):**
   - معرفی کامل آراد وفایی با آواتار، بیوگرافی و لینک‌های معتبر (گیت‌هاب، لینکدین، تلگرام، واتساپ، اینستاگرام و سایت شخصی).

## راهنمای ریپو کردن در گیت‌هاب و لایو کردن (Deploy):

### مرحله ۱: ایجاد ریپازیتوری در گیت‌هاب
۱. وارد سایت [GitHub.com/new](https://github.com/new) شوید.
۲. نام مخزن را بنویسید (مثلاً: `dorsa-dental-clinic`).
۳. روی **Public** بگذارید و تیک هیچ گزینه‌ای را نزنید و دکمه **Create repository** را بزنید.

### مرحله ۲: اتصال و ارسال به گیت‌هاب
در ترمینال در پوشه `Desktop/web2` دستورات زیر را وارد کنید:

```bash
git remote add origin https://github.com/v1rango/dorsa-dental-clinic.git
git push -u origin main
```

### مرحله ۳: فعال‌سازی با GitHub Pages
۱. در گیت‌هاب به **Settings** > **Pages** بروید.
۲. در قسمت **Branch** شاخه `main` و پوشه `/(root)` را انتخاب کرده و **Save** کنید.
۳. سایت شما در آدرس `https://v1rango.github.io/dorsa-dental-clinic/` لایو خواهد شد.
